# Лабораторная работа 1

## Ответы на вопросы

1. Чем отличается dotnet run от dotnet build?
dotnet build просто собирает программу, проверяет ошибки и делает файл. А dotnet run сначала собирает, а потом сразу запускает. Это удобно, чтобы быстро проверить, работает ли код.

2. Какие файлы появляются в bin/Debug/net10.0/ и зачем нужен .pdb?
Появляется файл .dll (сама программа) и .pdb. Файл .pdb нужен для отладки. В нем написано, какая строчка кода где находится, чтобы если ошибка, то программа показала, где именно она.

3. Что делает компилятор с файлом .cs? Почему процессор не может выполнить текст?
Компилятор превращает код C# в IL (промежуточный язык) и засовывает в .dll. Процессор не понимает текст. Он понимает только нули и единицы (машинный код), поэтому текст ему нельзя дать.

4. Зачем нужен .gitignore? Что будет, если закинуть папку bin?
.gitignore нужен, чтобы Git не загружал лишние файлы на GitHub. Если закинуть bin, то она будет весить много, и там мусорные файлы, которые всегда меняются. Будет мешать.

5. Какой тип данных выбрать?
* Фамилия - string (текст).
* Возраст - int (целое число).
* Средний балл - double (потому что там запятая, например 4.5).
* Отчислен или нет - bool (да или нет).

6. Что выведет Environment.ProcessorCount?
Он выведет сколько ядер у процессора. У всех разные цифры, потому что у кого-то компьютер мощный, а у кого-то нет. У меня 12 ядер.

7. Зачем вызывать Console.ResetColor()?
Чтобы цвет обратно стал обычным. Если не сделать, то весь текст дальше будет цветным, и это выглядит плохо.
